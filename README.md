# News Postcard Generator

A professional web application for generating high-quality news postcards, quote cards, and social media graphics. Built with Vite, React, TypeScript, and modern Vanilla CSS.

## Features

- **Real-time Preview**: See your postcard generated in real-time as you type or upload images.
- **High-Quality Export**: Export the generated postcard as a crisp PNG image using `html-to-image`.
- **Premium Aesthetics**: Features a modern, dark-themed UI with glassmorphism and subtle animations.
- **Customizable Metrics**: Add custom text, headlines, dates, and engagement metrics (likes, comments, shares).
- **Bengali Font Support**: Uses `Hind Siliguri` font for excellent Bengali typography.

## Tech Stack

- [Vite](https://vitejs.dev/) - Fast frontend build tool
- [React](https://reactjs.org/) - UI library
- [TypeScript](https://www.typescriptlang.org/) - Static typing
- [Lucide React](https://lucide.dev/) - Beautiful icons
- [html-to-image](https://github.com/bubkoo/html-to-image) - DOM to image generation

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Mehedi259/News-Postcard.git
   cd News-Postcard
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Deployment

This project is optimized for deployment on Vercel.

1. Install Vercel CLI (if not already installed):
   ```bash
   npm i -g vercel
   ```

2. Deploy:
   ```bash
   vercel
   ```
   Follow the prompts to link the project and deploy.
